# 更新進度紀錄

更新 `docs/progress.md`，**保持精簡**，整份檔案控制在 80 行內：

1. **進行中**：目前任務、對應規格檔、已完成的步驟（打勾）、下一步（具體到檔案或函式）。
2. **最近決策**：本次 session 做出、且程式碼看不出來的決策，一行一則，附日期。
3. **已知問題 / 待辦**：發現但還沒處理的問題。
4. **清理**：
   - 已完成超過兩週的項目移到「已完成」，只留一行摘要。
   - 已過時的內容直接刪除。
5. 如果某條決策會長期適用（例如「金額一律用 Decimal」），建議使用者寫進 CLAUDE.md，不要只留在進度檔。

完成後用 3 行內回報更新了什麼。
